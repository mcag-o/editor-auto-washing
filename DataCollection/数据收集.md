# DataCollection

## 项目定位

`DataCollection/` 是一个独立的 Node.js 热榜采集系统，用来复刻当前 Python 项目 `app/services/sites` 中的全部采集能力，并补足 README 与历史命名漂移带来的平台兼容问题。

系统统一覆盖三类数据来源：

- JSON API 直连采集
- HTML 页面抓取解析
- 浏览器回退抓取

所有平台输出统一标准 JSON 结构，便于后续接数据库、缓存、API 服务或前端展示层。

## 平台全集与采集能力

### 百度热搜 (`baidu`)

上游来源：`https://top.baidu.com/api/board?platform=wise&tab=realtime`
来源方式：JSON API
信息类型：实时热搜、热度值、摘要、跳转链接
典型返回：顶层 `data.cards[0].content[0].content[]`，列表字段包含 `word`、`url`、`desc`、`hotScore`
当前状态：可用
抓取策略：直接请求 JSON，必要时将 `m.baidu.com` 链接转成 `www.baidu.com`
反爬应对：常规 UA 即可，低风险

### 少数派 (`shaoshupai`, `sspai`)

上游来源：`https://sspai.com/api/v1/article/index/page/get?limit=20&offset=0&created_at=0`
来源方式：JSON API
信息类型：文章标题、文章 ID、摘要
典型返回：顶层 `data[]`，列表字段包含 `id`、`title`、`summary`
当前状态：可用
抓取策略：API 直连，按 `id` 拼接文章 URL
反爬应对：常规 UA 即可

### 微博热搜 (`weibo`)

上游来源：`https://weibo.com/ajax/side/hotSearch`
来源方式：JSON API
信息类型：热搜词、热度、搜索页链接
典型返回：顶层 `data.realtime[]`，字段包含 `word`、`raw_hot`
当前状态：条件可用
抓取策略：优先直连 Ajax 接口，输出为微博搜索页链接
反爬应对：支持 `WEIBO_COOKIE`、代理、稳定 UA；公开网络下可能返回 403

### 知乎热榜 (`zhihu`)

上游来源：`https://www.zhihu.com/api/v3/explore/guest/feeds?limit=30&ws_qiangzhisafe=0`
来源方式：JSON API
信息类型：问题标题、回答摘要、作者、赞同数
典型返回：顶层 `data[]`，深层字段在 `target.question`、`target.excerpt`、`target.author`
当前状态：可用
抓取策略：从内容流中抽取 `question.id` 和 `question.title`
反爬应对：常规 UA 即可

### 36Kr (`36kr`, `tskr`)

上游来源：`https://gateway.36kr.com/api/mis/nav/home/nav/rank/hot`
来源方式：JSON API
信息类型：热榜标题、文章 ID
典型返回：顶层 `data.hotRankList[]`，字段包含 `itemId`、`templateMaterial.widgetTitle`
当前状态：可用
抓取策略：POST 请求，发送 `partner_id` 与 `param.siteId/platformId`
反爬应对：使用浏览器 UA 和 JSON body

### 吾爱破解 (`52pojie`, `ftpojie`)

上游来源：`https://www.52pojie.cn/forum.php?mod=guide&view=hot`
来源方式：HTML 页面
信息类型：帖子标题、帖子链接、作者/版块简述
典型返回：DOM 节点 `tbody[id^="normalthread_"]`
当前状态：条件可用
抓取策略：请求 HTML 后解析 `.xst` 标题链接
反爬应对：稳定 UA；结构变化时需要更新 selector

### 哔哩哔哩 (`bilibili`)

上游来源：`https://api.bilibili.com/x/web-interface/popular`
来源方式：JSON API
信息类型：热门视频标题、视频号、描述、作者、播放量
典型返回：顶层 `data.list[]`，字段包含 `title`、`bvid`、`desc`、`owner`、`stat`
当前状态：可用
抓取策略：拼接 `https://www.bilibili.com/video/{bvid}`
反爬应对：带 `Referer: https://www.bilibili.com/`

### 豆瓣 (`douban`)

## 当前可直接使用的接口总结

按此前实测与当前实现综合判断：

- 稳定可直接使用：`baidu`、`shaoshupai`、`zhihu`、`bilibili`、`tieba`、`juejin`、`stackoverflow`、`github`、`hackernews`
- 条件可用：`weibo`、`36kr`、`douban`、`hupu`、`douyin`、`jinritoutiao`、`tenxunwang`、`sina_finance`、`eastmoney`、`xueqiu`、`cls`
- 结构依赖较强：`52pojie`、`v2ex`

## 反爬与稳态运行策略

- 统一超时控制：默认 10 秒
- 统一重试：指数退避，默认重试 2 次
- 并发控制：默认 4 并发
- 速率限制：核心运行时提供按平台限流器
- 代理支持：通过 `.env` 配置 `HTTP_PROXY` 与 `HTTPS_PROXY`
- Cookie 注入：通过 `.env` 配置 `WEIBO_COOKIE` 与 `XUEQIU_COOKIE`
- 浏览器回退：通过 `.env` 配置 `ENABLE_BROWSER_FALLBACK=true`
